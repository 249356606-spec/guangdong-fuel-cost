# 广东省燃料成本分析系统

## 系统说明

本系统用于收集、分析和可视化广东省燃煤发电机组和燃气发电机组的燃料采购成本数据，包括：
- CCTD动力煤价格
- 广州港进口动力煤价格
- LNG液化天然气价格（待开发）

## 文件结构

```
燃料成本/
├── fuel_cost_analyzer.html          # macOS风格的可视化界面
├── fuel_cost_analyzer.py            # 数据采集和分析工具
├── 广东省动力煤价格数据_2026年.csv   # 动力煤价格数据
├── 燃料成本分析报告_*.txt            # 分析报告
└── README.md                        # 项目说明文档
```

## 功能特性

### 1. macOS风格可视化界面
- 现代化的用户界面设计
- 实时数据图表展示
- 历史数据表格
- 数据输入和管理功能

### 2. 数据采集工具
- 自动从官方渠道采集数据
- 支持手动数据输入
- 数据验证和清洗

### 3. 数据分析功能
- 基本统计分析
- 价格趋势分析
- 自动生成分析报告

## 使用说明

### 1. 启动可视化界面

在浏览器中打开 `fuel_cost_analyzer.html` 文件：

```bash
# macOS系统
open ~/Desktop/燃料成本/fuel_cost_analyzer.html

# 或者直接双击文件
```

### 2. 运行数据采集工具

```bash
cd ~/Desktop/燃料成本
python3 fuel_cost_analyzer.py
```

### 3. 数据输入

在可视化界面中：
1. 选择日期
2. 输入各类型动力煤价格
3. 点击"添加数据"按钮

### 4. 查看分析报告

运行数据采集工具后，会在燃料成本文件夹中生成分析报告。

## 官方数据获取渠道

### 1. CCTD中国煤炭市场网
- 网址：www.cctd.com.cn
- 主办单位：中国煤炭运销协会
- 数据内容：CCTD环渤海动力煤现货参考价
- 更新频率：每日更新

### 2. 广东省能源运销协会
- 网址：www.gdetsa.org.cn
- 数据内容：广州港煤炭价格、库存信息
- 更新频率：每日更新

### 3. 我的钢铁网
- 网址：www.mysteel.com
- 数据内容：广州港动力煤港口价格
- 更新频率：实时更新

- 广州港进口煤5500大卡（元/吨）：广州港进口动力煤5500大卡价格
